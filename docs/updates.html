Updates

One source of truth. This page reads release notes straight from GitHub Releases, so the changelog is never out of sync with the jar.

How official builds ship

  1. A tagged build is published on GitHub Releases.
  2. The jar and sources jar are attached to that release.
  3. This site reads the public GitHub API.
  4. The newest note appears here and on the download page automatically.

Which file do I need?

Download the plain .jar. The -sources.jar asset is for developers who want to read the mod code and is not needed to play.

Third-party mirrors are not official. Always check the Releases page.
