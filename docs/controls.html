PILOT GUIDE / 02

Controls

Every binding is rebindable in Minecraft. These are the defaults, plus the few keys with special Flight Line behavior.

First flight in six steps

  1. Press E to start engines while flight is active.
  2. Use W / S for throttle and look up or down to pitch.
  3. Use A / D for rudder and bank, then rotate at the airframe's rotate speed.
  4. Raise gear with G and step flaps in with C / V.
  5. Open the flight deck with H to set heading, altitude, vertical speed and IAS.
  6. On approach, use X spoilers, N airbrakes and M wheel brakes.

Special key behavior

A few keys intentionally do more than one thing.

E — engine start

  • While engines are off, E starts them instead of opening your inventory.
  • Inventory is blocked during the start sequence.
  • Once engines are running, E behaves normally.
  • After a crash, E resets the aircraft.

G — landing gear

  • Vanilla quick actions are drained while flight is active.
  • The client mixin also suppresses conflicting vanilla keys in flight.
  • Gear state is authoritative on the server.

F7 — ATC release

  • If you are under that controller's command, F7 is a release request.
  • Otherwise it acknowledges a pending ATC message.
  • Manual throttle or bank input also releases control.

O & T — checklists

  • O opens the situation and procedure panels.
  • T executes the highlighted next action.
  • The server revalidates every action before applying it.

Flight deck and ILS autoland

Press H for the four-page flight deck. The MCP holds heading, altitude, vertical speed and IAS targets, with SYNC and LEVEL shortcuts. The NAV/ILS page configures approaches, WX shows layered storm cells and traffic, and SYS shows the aircraft schematic and system status.

  • /flightline ils set 1-6 — set glide slope, default 3.0
  • /flightline ils clear — remove the localizer
  • H → NAV/ILS → AUTOLAND — engage the approach

Autoland needs airborne flight, valid same-dimension ILS coverage, serviceable gear, a running engine and enough airspeed margin. It targets 130 kt, manages gear and flaps, and drops ATC control before taking over. Normal or emergency autoland also releases ATC control.
